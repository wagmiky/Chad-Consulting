# Анализ конкурентов

Эта часть отвечает на вопрос: как устроен рынок курсов по стилю и
уходу для мужской аудитории, и куда нам ложиться по цене и формату.

Данные из двух источников. Подборку курсов сохранил как HTML и
распарсил через BeautifulSoup: 20 курсов от 8 школ с ценой,
длительностью и форматом. Плюс семь YouTube-каналов блогеров по теме
через yt-dlp: подписчики и средние просмотры. Суммарная аудитория
954 580 подписчиков, медиана 95 742 на канал. Кеш в `data/`.

В анализе: описательная статистика по ценам, две гипотезы через
Mann-Whitney U (one-sided), Spearman-корреляция цены и длительности,
bootstrap-CI для медианы цены, k-means на (цена, длительность) с
elbow plot для выбора k. Результаты идут в `reports/report.md` и в
дашборд на Dash.

## Запуск

    pip install -r requirements.txt
    python run.py
    python dashboard.py

## Результаты

Гипотеза 1. Внутри онлайн-сегмента ментор-курсы дороже за месяц
обучения, чем групповые вебинарные. Медиана 16 633 ₽ за месяц у курсов
с ментором против 7 208 ₽ у групповых, разница значимая. То есть
рынок берёт надбавку именно за персональное внимание, а не за сам
факт сопровождения.

Гипотеза 2. Офлайн дороже онлайна в пересчёте на месяц обучения.
Медиана 26 333 ₽ за месяц у офлайна против 8 750 ₽ у онлайна, разница
значимая. Часть рыночной цены приходится на надбавку за формат, а не
за длительность.

Spearman ρ = 0.81 между ценой и длительностью, связь сильная и
положительная.

K-means выделил три сегмента: бюджетный (5 школ, 7 020 ₽, 1 месяц,
online_self), средний (8 школ, 24 512 ₽, 2 месяца, online_group)
и премиум (7 школ, 59 786 ₽, 3 месяца, online_mentor). Бутстрэп-медиана
цены по всем 20 курсам составила 25 700 ₽ с 95%-ным доверительным интервалом
[13 700; 47 450].

Между бюджетным и средним есть незанятая ниша по цене и формату. В неё
ложатся короткие практические модули с лёгким сопровождением, ориентир
по цене 14-15 тысяч.
