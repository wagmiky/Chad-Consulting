# Анализ конкурентов

Моя часть проекта Chad Consulting. Идея компании: онлайн-курсы по стилю,
уходу за кожей и луксмаксингу для парней 18-28. Тут я смотрю, кто уже
делает похожее на рынке, по каким ценам и в каких форматах, чтобы понять
куда нам ложиться по позиционированию.

## Откуда брал данные

Два источника, как требует методичка.

`data/courses_catalog.html`: сохранённая HTML-страница с подборкой курсов
по теме. Парсю её через BeautifulSoup, достаю из карточек школу, цену,
длительность и формат. Это статический парсинг. Один раз скачал страницу
и работаю офлайн, чтобы не зависеть от сети и иметь воспроизводимый
датасет.

`data/youtube_cache.csv`: данные по семи YouTube-каналам блогеров по теме,
собранные через `yt-dlp`. Беру число подписчиков и средние просмотры,
кешу в CSV. Если хочется пересобрать, есть флаг `--refresh`. Идея в
том, что конкуренты это не только школы, но и инфлюенсеры, которые
забирают аудиторию через личный бренд.

## Что в проекте

`collector.py`: классы `CourseScraper` и `YouTubeFetcher`, плюс функция
склейки в одну таблицу конкурентов.

`analysis.py`: класс `CompetitorAnalysis`. Считает базовую статистику по
ценам, проверяет две гипотезы через Mann-Whitney U (one-sided), смотрит
Spearman-корреляцию цены и длительности, делает bootstrap для
доверительного интервала медианы. Дальше k-means с предварительным
elbow для выбора k. Все графики и итоговый markdown-отчёт собираются
тоже отсюда.

`dashboard.py`: интерактивный дашборд на Dash, три вкладки. Обзор школ
с фильтром по формату, карта позиционирования и блок про кластеры и
гипотезы.

`run.py`: точка входа. Запускаешь и получаешь отчёт + графики в
папке `reports/`.

## Запуск

```bash
pip install -r requirements.txt
python run.py             # собираем, считаем, пишем отчёт
python run.py --refresh   # пересобрать YouTube кеш через yt-dlp
python dashboard.py       # дашборд на :8050
```

## Что получилось по выводам

Курсы с ментором значимо дороже самостоятельных, p < 0.01. То есть формат
сопровождения это отдельный ценовой сегмент.

Офлайн дороже онлайна не только по абсолютной цене, но и в пересчёте
на месяц обучения (p < 0.01). Значит часть цены это надбавка за формат,
а не просто длительность. Для нашего онлайн-продукта верхняя граница
прайса ниже офлайн-школ.

Кластеризация выделила три понятных сегмента: бюджетный самозанимающийся
сегмент (~7 000 ₽, 1 месяц), средний групповой (~24 500 ₽, 2 месяца)
и премиум с ментором (~60 000 ₽, 3 месяца). Между бюджетным и средним
есть дырка, куда ложится наш продукт: короткие практические модули
с лёгким сопровождением, по цене около 14-15 тысяч.

Подробные числа и графики в `reports/report.md`.

## Что закрывает по курсу

- ООП: три класса с разной зоной ответственности.
- Dash-дашборд с тремя вкладками.
- Гипотезы и оценка выборок: Mann-Whitney U, bootstrap-CI, Spearman.
- Графики: matplotlib для статики и Plotly внутри дашборда.
- Парсинг: BeautifulSoup на сохранённой HTML-странице.
- Кластеризация: k-means с выбором k по elbow.
