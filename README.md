# Анализ конкурентов

Эта часть отвечает на вопрос: как устроен рынок онлайн-курсов по стилю
и работе с внешностью в России, и куда нам ложиться по цене и формату.

## Данные

Два источника.

Первый, `data/courses_catalog.html`: сводка карточек курсов с публичных
страниц шести школ: ВШИС, Эколь, Skillbox, Нетология, Fashion Factory
School, Европейская Академия Имиджа. Снапшот май 2026. Парсю BeautifulSoup-ом
и достаю школу, цену, длительность и формат. Получается 13 курсов.

Второй, `data/youtube_cache.csv`: метрики шести русскоязычных YouTube-каналов
по теме стиля и работы с внешностью. ROGOV LIVE (Александр Рогов),
ШЛЯПА (Григорий Пронин), Егор Настоящий, Антон Сорвачев, Salavat Kypere
(Виктория Чураева), Emil. Через `yt-dlp` подтянул подписчиков и средние
просмотры, результат закеширован. Суммарная аудитория 1 696 304 подписчика,
медиана 105 509 на канал.

## Что в анализе

Описательная статистика по ценам, две гипотезы (Mann-Whitney и Spearman),
bootstrap-CI медианы цены, k-means на (цена, длительность) с предварительным
elbow plot для выбора k. Результаты идут в `reports/report.md` и в
дашборд на Dash.

## Запуск

    pip install -r requirements.txt
    python run.py
    python dashboard.py

## Результаты

Гипотеза 1. Цена за месяц обучения у крупных edtech-платформ (Skillbox,
Нетология, Fashion Factory School) значимо выше, чем у нишевых школ
стиля (Эколь, ВШИС, Европейская Академия Имиджа). Медиана 22 378 ₽ за
месяц у edtech против 14 600 ₽ у традиционных, разница значимая по
Mann-Whitney. Часть рыночной цены это надбавка за бренд и маркетинг
крупной edtech, а не только за качество программы.

Гипотеза 2. Цена и длительность курса связаны положительно. Spearman
ρ = 0.89 на 13 наблюдениях, значимо. Простыми словами: чем длиннее
программа, тем дороже она стоит в абсолюте, без признаков «оптовой
скидки».

Бутстрэп-медиана цены по всем 13 курсам составила 35 900 ₽ с 95%-ным
доверительным интервалом [14 600; 80 900]. Разброс огромный, это в основном из-за
двух полюсов рынка (профшколы по 13-30к и edtech по 60-150к).

K-means выделил три сегмента: «нишевый» (7 школ, средняя цена 21 129 ₽,
1 месяц): короткие курсы Эколь, ВШИС, Европейской Академии. «Edtech-средний»
(5 школ, 87 180 ₽, 4 месяца): основные программы Skillbox, Нетологии,
Fashion Factory School. «Edtech-премиум» (1 школа, 147 188 ₽, 6 месяцев):
Skillbox Fashion-стилист как выброс.

YouTube-конкуренты это отдельный тип игрока. 6 каналов в выборке держат
суммарно 1.7 миллиона подписчиков. Они забирают часть аудитории,
которая иначе бы шла в курсы, но не продают обучение как продукт,
а монетизируются рекламой и личным брендом.

## Где наша ниша

Прямых B2C-курсов «стиль и уход для парней 18-28» на российском рынке
почти нет. Почти все курсы из выборки это профессиональные программы
для будущих стилистов (B2P), а не для конечного потребителя. Это и есть
свободное место.

Между «нишевым» сегментом (13-30к за 1-2 месяца профобучения) и
«edtech-средним» (60-150к за полугодовую программу) есть зазор по цене
и формату. Наш продукт ложится туда: короткие тематические модули с
лёгким сопровождением, ориентир по цене 14-15 тысяч. Это дешевле 69%
курсов на рынке.

YouTube из выборки используется как канал привлечения, а не как
конкурент в чистом виде. Партнёрства с каналами среднего размера
(40-130 тысяч подписчиков, ШЛЯПА, Егор Настоящий, Антон Сорвачев)
дают точечный охват нашей ЦА дешевле, чем платный трафик.
