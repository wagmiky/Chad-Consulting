# Анализ конкурентов

Моя часть общего проекта Chad Consulting. Идея у нас: онлайн-курсы по
стилю, уходу за кожей и луксмаксингу для парней 18-28. Прежде чем что-то
запускать, я хотел понять кто уже делает похожее, по каким ценам и в
каких форматах. Это и есть тут.

## Откуда взял данные

Два источника.

Первый — `data/courses_catalog.html`. Я нашёл подборку курсов по теме и
сохранил страницу как HTML. Парсю её через BeautifulSoup, достаю из
карточек школу, цену, длительность и формат. Получается двадцать
курсов от восьми школ.

Второй — `data/youtube_cache.csv`. Конкуренты ведь не только школы, есть
ещё блогеры по теме, которые забирают аудиторию через личный бренд. Я
взял семь каналов, через `yt-dlp` подтянул подписчиков и средние
просмотры. Результат закеширован, чтобы не дёргать ютуб каждый раз.
Пересобрать можно командой `python run.py --refresh`.

## Что в коде

`collector.py` — два класса для сбора: один тянет курсы из HTML, второй
ходит в YouTube.

`analysis.py` — основной анализ. Считаю описательную статистику по ценам,
проверяю две гипотезы через Mann-Whitney, смотрю Spearman-корреляцию,
делаю bootstrap для доверительного интервала медианы. Дальше k-means
на (цена, длительность) с предварительным elbow plot для выбора k.
Графики и итоговый markdown собираются тоже отсюда.

`dashboard.py` — Dash приложение на три вкладки. Обзор школ, карта
позиционирования и блок про кластеры с гипотезами.

`run.py` — главный скрипт. Запускаешь и получаешь отчёт.

## Запуск

```
pip install -r requirements.txt
python run.py
python dashboard.py
```

После `run.py` смотри `reports/report.md` и графики там же.

## К чему я пришёл

Курсы с ментором стоят сильно дороже самостоятельных, и это
статистически значимо, а не просто впечатление по паре примеров.

Офлайн дороже онлайна, это понятно. Но я отдельно проверял цену не в
абсолюте, а на месяц обучения. И там офлайн всё равно выше. Значит часть
рыночной цены это надбавка именно за формат, а не за длительность. Для
нашего онлайн-продукта это значит, что верхняя граница нашей цены ниже
офлайн-школ, даже если курс длится столько же.

Через k-means получились три понятных сегмента. Бюджетный
(самозанимающийся, около 7 000 ₽, один месяц), средний (групповые
вебинары, около 24 500 ₽, два месяца) и премиум (с ментором, около
60 000 ₽, три месяца). Между бюджетным и средним есть промежуток по
цене и формату, куда ложится наш продукт: короткие модули с лёгким
сопровождением за 14-15 тысяч.

Цифры и графики в `reports/report.md`.
